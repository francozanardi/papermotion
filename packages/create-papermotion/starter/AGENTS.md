# Guide for agents working in this papermotion project

This project was created with `npm create papermotion`. It holds a copy of the papermotion engine
(`src/`), its tools (`scripts/`) and its tests; the films live in `examples/`.

Read `README.md` first, and `docs/field-notes.md` before making a scene: it collects the mistakes
made while building the engine and the fixes that worked. To make a short, use the skill in
`.claude/skills/papermotion/` (or `.agents/skills/papermotion/`): workflow, API reference, art
direction, pitfalls, sound and inspection.

## Principles

- **The engine is yours to extend.** `src/` is a generic engine; `examples/` is content. If a scene
  needs a behaviour that another scene could use (a way to move, a contact, a paper effect, a sound),
  add it to `src/` as a parameterised primitive, with a test and an export in `src/index.ts`, not as a
  one-off in the scene.
- **Generated by code.** No image or sound assets, no image or music models. Characters and props are
  rigs and parametric makers drawn with `Paper`; sounds are synthesized.
- **Life at bone level.** Motion comes from springs, strands and physics driven by intents
  (speed, reach, look, beats), never from keyframing positions.
- **Acceptable within the universe.** Physics should read right in a paper world, not be realistic.
- **Deterministic.** Fixed timestep, seeded `rng`, no `Math.random`, no wall-clock time. The same frame
  always renders the same image.

## Conventions

- TypeScript strict. One class per file, named after the class; function modules use camelCase.
- TSDoc on public API. Minimal inline comments: explain the non-obvious, not the code.
- Scenes live in `examples/<name>/` and are registered in `examples/catalog.ts`.
- Scenes import only from the public API (`../../src`), never from engine internals.
- Tests live in `tests/` (Vitest, node environment); anything that needs a canvas is checked by rendering.

## Commands

```bash
pnpm render hello              # offline render → out/hello.mp4 (or: all)
pnpm dev                       # vite on :5299 — /?example=hello plays the render, &live runs it live
pnpm grab hello 1 2 3 [--probe]  # frames and/or probes at those seconds → out/grab/
pnpm sheet hello               # contact sheet of out/hello.mp4
pnpm listen hello              # soundtrack only (scenes with a `soundtrack`): wav, spectrogram, loudness, cues
pnpm test
pnpm typecheck
```
