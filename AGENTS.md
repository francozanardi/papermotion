# papermotion — guide for agents working on this codebase

Read `README.md` first for what each module does, and `docs/field-notes.md` before making a scene:
it collects the mistakes we made and the fixes that worked. To make a short, use the skill in
`.claude/skills/papermotion/` (workflow, API reference, art direction, pitfalls, inspection).

## Principles

- **Engine vs content.** `src/` is a generic engine; `examples/` is content. If a scene needs a
  behaviour that another scene could use (a way to move, a contact, a paper effect), it belongs in
  `src/` as a parameterised primitive — not as a copy in the next example, and not as a one-off asset.
- **Generated by code.** No image assets, no image models. Characters and props are rigs and
  parametric makers drawn with `Paper`.
- **Life at bone level.** Motion comes from springs, strands and physics driven by intents
  (speed, reach, look, beats), never from keyframing positions.
- **Acceptable within the universe.** Physics should read right in a paper world, not be realistic.
- **Deterministic.** Fixed timestep, seeded `rng`, no `Math.random`, no wall-clock time. The same frame
  always renders the same image.

## Conventions

- TypeScript strict. One class per file, named after the class (`Swimmer.ts`); function modules use
  camelCase (`steer.ts`, `flora.ts`). Auxiliary types may live next to what uses them.
- TSDoc on public API. Minimal inline comments: explain the non-obvious, not the code.
- New examples are registered in `examples/catalog.ts`.
- Examples import only from the public API (`../../src`), never from engine internals.
- Add public symbols to `src/index.ts`.
- Tests live in `tests/` (Vitest, node environment); anything that needs a canvas is checked by rendering.

## Commands

```bash
pnpm render sea   # offline render → out/sea.mp4 (or: all)
pnpm dev          # vite on :5299 — /?example=sea plays the render, &live runs it in the browser
pnpm grab sea 1 4 7 [--probe]   # frames and/or probes at those seconds → out/grab/
pnpm sheet sea                  # contact sheet of out/sea.mp4
pnpm test
pnpm typecheck
```
